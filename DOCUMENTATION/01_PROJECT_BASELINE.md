# 01 Project Baseline
## Architecture
- Frontend: React (Vite build system), TypeScript, CSS Modules
- Backend: None (No Django backend, APIs, or Database configured in this repository).
- Database: None
- State Management: React useState hook
- Routing: React Router (HashRouter)

## Modules
- OPD Workflows
- IPD Workflows
- Billing & Deposits
- Dashboards & Reports
- Master Data Management (Room, Bed, Doctor, etc.)

## Initial Failures
- The repository only contains the UI layer. There is no backend logic.
- Hardcoded dummy data has been entirely stripped, leaving the application in a pure empty UI state.
